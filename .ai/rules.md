# Rules

These rules are strict. Follow them in every file you write or edit.

1. Never use complex coding. Always write simple, beginner-level code: function-based views, plain models and forms, short readable functions.
2. No comments in code. Not one line, not a docstring.
3. No em dashes anywhere (code, docs, commit messages, replies). Use a comma, a colon, or a new sentence instead.
4. UI uses only basic Bootstrap 5 (Bootstrap CSS and its JavaScript bundle for standard components like the navbar, no custom styling, nothing advanced). The app runs locally only.
